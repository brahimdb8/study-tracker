## نموذج البيانات (schemaVersion = 5)

```js
{
  schemaVersion: 5,
  sessions: [{ id, date, period, minutes, startedAt, source, subject, note, createdAt }],
  dayMeta:  { "2026-11-12": { quality: "good" } },
  subjects: [{ id, name, color, archived }],
  dayOffs:  [{ id, from, to, type: "rest|sick|exam|vacation", note }],
  exams:    [{ id, name, date }],                       // جديد في 5 (حتى 20، الاسم ≤ 40)
  achievements: { unlocked: { "streak-7": "2026-11-10" } }, // جديد في 5: معرّف الوسام ← تاريخ تحقق شرطه
  plan:     { versions: [{ effectiveFrom, targets: { 0..6: { morningMins, eveningMins } }, weeklyMins }] },
  settings: {
    trackingStart, freezesPerMonth,
    timer: { focusMins: 25, shortMins: 5, longMins: 15, longEvery: 4, sound: true, notify: false }
  }
}
```

اسم مفتاح التخزين `studyTracker:v2` تسمية تاريخية لمساحة التخزين، وليس رقم المخطط.

## قواعد حالة اليوم

| الحالة | المعنى |
|---|---|
| `completed` | بلغ مجموع اليوم الهدف |
| `compensated` | ناقص، لكن مجموع الأسبوع بلغ هدف الأسبوع |
| `failed` | مقصّر (انتهى أسبوعه أو سُجّل فيه دون بلوغ الهدف) |
| `frozen` | كان سيقطع السلسلة فجُمِّد تلقائياً |
| `excused` | يوم استثنائي (إجازة/مرض/امتحان/راحة يدوية) |
| `rest` | الخطة تجعل هدفه صفراً |
| `default` | لم يُحسم بعد (اليوم الحالي، أو يوم فات والأسبوع مفتوح) |

- **الاستثنائي والراحة:** محايدان في السلسلة، ويُطرح هدفاهما من هدف الأسبوع والشهر. الدقائق المدرسة فيهما تُحتسب ضمن المُنجَز.
- **التجميد:** يحمي سلسلة قائمة فقط، وتُجمَّد أول N أيام كاسرة في كل شهر. محسوب من البيانات لا مخزَّن، فإن عُوِّض يوم لاحقاً زال تجميده. اليوم المجمّد لا يزيد السلسلة.
- **هدف الأسبوع:** `weeklyMins` إن حُدِّد، وإلا مجموع الأهداف اليومية؛ مطروحاً منه أهداف الأيام الاستثنائية والأيام قبل بداية التتبع.

## المؤقت (المرحلة 4: بومودورو)

- **الدورة:** تركيز → استراحة قصيرة تبدأ تلقائياً → يعود المؤقت إلى `idle` وينتظر بدءك. بعد `longEvery` جلسات تركيز تأتي استراحة طويلة وتُغلق الدورة. عدّاد الدورة يُصفَّر عند اليوم الجديد.
- **التسجيل:** تُسجَّل جلسة التركيز المكتملة فقط بمعرّف ثابت `pomo-<startedAt>` وبـ`startedAt` الفعلي، فلا تتكرر مع إعادة التحميل أو تبويبين. الاستراحات لا تُسجَّل. «إنهاء وحفظ» يحفظ الدقائق الكاملة المنقضية (دقيقة فأكثر).
- **الاستعادة:** الحالة تُحفظ تحت `studyTracker:pomodoro` (مستقلة عن بيانات التطبيق). إن انتهى طور أثناء إغلاق الصفحة يُحسب من وقته الفعلي (جلسة واحدة بلا جلسات وهمية). مؤقت المراحل 1–3 الجاري (`studyTracker:timer`) يُحوَّل إلى تركيز جارٍ بوقته ووقت بدئه.
- **الإعدادات** (`settings.timer`، من settings.html): التركيز 1–180، القصيرة 1–60، الطويلة 1–120، `longEvery` 2–10، ونغمة (افتراضياً مفعّلة) وإشعارات المتصفح (مطفأة حتى تمنح الإذن). التغيير يسري من الطور التالي.
- **إشعارات المتصفح:** تعمل والصفحة مفتوحة (حتى في تبويب خلفي) ولا تصل والمتصفح مغلق قبل المرحلة 8 (PWA). يُطلب الإذن من نقرتك فقط.
- **Wake Lock:** يُطلب أثناء التركيز الجاري فقط ويُعاد طلبه عند العودة للتبويب؛ يُتجاهل بصمت إن لم يدعمه المتصفح.
- **ألوان الحلقة:** `--ring-focus: #3987e5` و`--ring-break: #c98500` على سطحَي التطبيق الداكنين، اجتازت كل فحوصات `validate_palette` (CVD ΔE ≥ 24). الحلقة زخرفية؛ الوقت واسم الطور نصوص دائماً.

## المرحلة 5: التجربة وإمكانية الوصول والتصدير

**الثيمان (فاتح/داكن/تلقائي):** كل الألوان رموز في `src/styles/tokens.css` (الداكن افتراضي، والفاتح عبر `prefers-color-scheme` أو `data-theme`). الاختيار لكل جهاز في `localStorage` بالمفتاح `studyTracker:theme`، وسكربت صغير في `<head>` يضبطه قبل الرسم فلا وميض. كتلتا الفاتح في tokens.css يجب أن تتطابقا (يحرسه `tests/tokens.test.js`، الذي يفرض أيضاً تباين ≥4.5 للنص و≥3 لغير النص في الثيمين). ألوان المواد في `subjects.js` بيانات وليست رموزاً.

**التحقق من اللوحة (validate_palette):** صباح/مساء داكن `#c98500,#9085e9` ΔE 27.5، فاتح `#b87a00,#6250d6` ΔE 33.5؛ سلم الخريطة الحرارية ordinal ناجح في الثيمين؛ ألوان الحالات تُرفق دائماً برمز ونص (✓ ≈ ✕ ❄ ☾ –) فلا يعتمد المعنى على اللون وحده.

**إمكانية الوصول:** التقويم شبكة ARIA بـ roving tabindex. الأسهم (RTL: ← = اليوم التالي)، ↑/↓ أسبوع، Home/End أحد/سبت، PageUp/PageDown شهر (مع Shift سنة)، Enter للتحديد (`src/core/calendar-nav.js` نقي). فحص axe-core (wcag2a/aa/21aa) على كل الصفحات في الثيمين على الحاسوب والجوال: صفر مخالفات.

**التراجع بدل التأكيد:** حذف الجلسة فوري مع إشعار «تراجع» 6 ثوانٍ (وCtrl/⌘+Z). الاستيراد يُتراجَع عنه 10 ثوانٍ، وزر «استعادة النسخة السابقة» في الإعدادات (`swapPreImportBackup` متماثلة فلا يضيع شيء).

**الشاشة التعريفية:** 3 خطوات لمن لا جلسات ولا مواد لديه (`src/core/onboarding.js`، علم `studyTracker:onboarded`)، تحبس التركيز، Esc/تخطي، واختيار مواد اختياري ولا تمس الخطة.

**التصدير:** CSV للجلسات وملخص يومي (UTF-8 BOM، CRLF، فاصل `;` أو `,`، تحييد حقن الصيغ)، وتقرير طباعة `print.html` (A4، ثابت فاتح) يُحفظ PDF من نافذة الطباعة. المنطق في `export-csv.js` و`report.js` النقيين.

**الاختبارات:** 225 اختبار وحدة (`tests/phase5.test.js` جديد) + فحوص Playwright مؤقتة غير مشحونة: ثيمان × (حاسوب 1280 / جوال 390)، لا تمرير أفقي، صفر أخطاء console.

## المرحلة 6: التصميم الحيوي + تجربة الحاسوب + الإنجازات

**الهيكل:** `shell.js` يبني شريطاً جانبياً ثابتاً (≥1024px، على اليمين) يتحول إلى شريط سفلي + شريط علوي صغير على الجوال، من قائمة صفحات واحدة (`nav-model.js`). زر الثيم وزر الاختصارات في ذيل الشريط. الرئيسية عمودان من 1100px. `print.html` بلا هيكل عمداً.

**الاختصارات** (`shortcuts.js`): `N` جلسة جديدة · `T` بدء المؤقت، وإن كان جارياً إيقاف مؤقت/استئناف (الإنهاء والحفظ بالزر فقط) · `1` الرئيسية `2` التحليلات `3` الأوسمة `4` الإعدادات · `؟` نافذة المساعدة. لا تعمل أثناء الكتابة ولا مع نافذة مفتوحة ولا مع Ctrl/⌘/Alt (فيبقى Ctrl+Z للتراجع)، وتعمل مع التخطيط العربي (تعتمد `e.code`). من صفحة غير الرئيسية يفتح `N` وT الرئيسية عند `#new` / `#timer`.

**الحركة:** انتقالات ناعمة واحتفال جزيئات خفيف (28 عنصر CSS، بلا مكتبات) عند إتمام هدف اليوم أو الأسبوع أثناء الاستخدام الحي (مرة لكل يوم/أسبوع) وعند فتح وسام. `prefers-reduced-motion` يُحترم دائماً، ومفتاح «تعطيل الحركة والاحتفالات» في الإعدادات يضبط `data-motion="off"` (يقرؤه سكربت `<head>` قبل الرسم). مع التعطيل يبقى إشعار نصي (aria-live) بلا جزيئات.

**الأوسمة (14):** سلاسل 3/7/30/100 · ساعات 10/50/100/500/1000 · تنوع (3 مواد في أسبوع؛ كل المواد النشطة في شهر، بحد أدنى مادتان نشطتان) · عادات (أسبوع كامل منتهٍ بـ3 أيام مستهدفة على الأقل؛ شهر منتهٍ ≥90% بـ10 أيام مستهدفة على الأقل؛ 5 أيام متتالية تبلغ هدف الصباح، وإن كان هدفه 0 فأي دقائق صباحية). التاريخ المخزَّن هو يوم تحقق الشرط فعلاً. الإضافة فقط: لا يُسحب وسام بعد حذف جلسات أو كسر سلسلة، ولا يتكرر فتحه. التقييم داخل `store` عند التحميل والحفظ والاستيراد، ويُعلَن عبر `takeUnlocks()`.

**بطاقة العد التنازلي:** تعرض أقرب امتحان قادم و«+N أخرى»؛ تُدار الامتحانات من قسم جديد في الإعدادات (حذف مع تراجع).

**بطاقة الإنجازات:** زر في التحليلات يفتح نافذة (أسبوع/شهر، إخفاء أسماء المواد افتراضياً) ويرسم PNG 1080×1350 على canvas (داكنة ثابتة)، حفظ أو مشاركة (Web Share عند الدعم). لوحة الصباح/المساء #c98500/#9085e9 على #1e293b تجتاز validate_palette.

**مفاتيح لكل جهاز (لا تُزامَن في المرحلة 9):** `studyTracker:theme`, `:onboarded`, `:exportPrefs`, `:pomodoro`, **`:motion`**, **`:celebrated`** (آخر يوم/أسبوع احتُفل به).

## المرحلة 8: IndexedDB وPWA ومعالج الترحيب والأوسمة الديناميكية (v0.9.0، المخطط يبقى 5 بلا ترقية)

### 8أ. التخزين في IndexedDB
- كاش متزامن في الذاكرة يُملأ من IndexedDB عند الإقلاع (`src/data/boot.js` بـ top-level await)، والكتابة «write-through» مجمَّعة، وتُفرَّغ عند `visibilitychange/pagehide`، وتُعاد المحاولة عند الفشل مع إشعار.
- ترحيل لمرة واحدة من localStorage، **وتبقى النسخة القديمة** (لا كتابة عليها) مع زر «حذف النسخة القديمة» بنقرتين في الإعدادات.
- مفاتيح الجهاز (الثيم، الترحيب، التصدير، المؤقت، الحركة، الاحتفال، تفضيل الإحصاءات) تبقى في localStorage ولا تدخل IndexedDB ولن تُزامَن في المرحلة 9.
- تراجع تلقائي إلى localStorage إن لم يتوفر IndexedDB أو تأخّر (4 ثوانٍ) أو فشل الترحيب.
- مزامنة التبويبات عبر `BroadcastChannel`: تعديل في تبويب يُظهر إشعار «تحديث» في الآخر.
- طلب `navigator.storage.persist()` مرة واحدة، بعد أن يسجّل المستخدم أول جلسة.

### 8ب. PWA والعمل دون اتصال
- `sw.js` مكتوب يدوياً، وقائمة الـ precache تُحقن عند البناء بإضافة Vite (`vite-plugin-sw-manifest.js`) مع بصمة إصدار تسمّي الكاش. كاش أول لطلبات GET من نفس الأصل فقط؛ الطلبات الخارجية وغير GET لا يلمسها إطلاقاً.
- لا تفعيل تلقائي: عند نزول نسخة جديدة يظهر إشعار «تحديث»، ولا يتبدل شيء إلا بنقرة المستخدم (ثم إعادة تحميل واحدة).
- `manifest.webmanifest` + أيقونات (192/512/maskable/apple-touch)، وبطاقة «التطبيق» في الإعدادات: حالة الجاهزية، الإصدار، زر تثبيت، تعليمات iOS، «تحقق من التحديث».
- `public/_headers` لـ Netlify: `sw.js` وmanifest وhtml بلا تخزين طويل، و`/assets/*` immutable.

### 8ج. الأوسمة الديناميكية
- التقييم تاريخي من السجل الحالي: تاريخ الفتح = أول يوم تحقق فيه الشرط. القائمة المخزّنة `unlocked` نسخة تُوفَّق عند كل حفظ وإقلاع واستيراد واستعادة.
- حذف الجلسة المخالفة يسحب الوسام (ونقاطه) تلقائياً مع إشعار «↩️ سُحب وسام…» لا يُكتم، وتُحفظ نسخة تدقيق احتياطية مرة واحدة قبل أول سحب.
- التراجع عن الحذف يعيد الوسام.

### 8د. معالج الترحيب التفاعلي
- يظهر تلقائياً لمن لا جلسات ولا مواد له ولم يُنهه من قبل: ترحيب ← المواد (مقترحات + مادة مخصصة) ← ساعات الأسبوع (حقل بتحقق فوري ومعاينة التوزيع على الأيام) ← ملخص، وفيه «ابدأ المذاكرة» أو «ابدأ مع جولة سريعة».
- المنطق نقي في `src/core/wizard.js`: `parseWeeklyHours` (يقبل الأرقام العربية)، `distributeWeekly` (بمضاعفات 5 دقائق ومجموعها يطابق الهدف تماماً، نهاية الأسبوع أثقل)، `applyWizard`.
- **الخطة تسري فوراً** (تُستبدل نسخة EPOCH) لأن المستخدم الجديد بلا سجل يُحمى؛ وإن وُجدت جلسات لا تُمَسّ الخطة أبداً.
- التخطي يضبط علامة الترحيب بلا تغيير في البيانات. الجولة المصوّرة ذات الخطوات السبع تبقى متاحة من الإعدادات («إعادة الجولة»)، ونصها عن الأوسمة حُدّث ليطابق الدلالة الديناميكية.
- نصوص المعالج كلها بـ `textContent`، والألوان من tokens، وفخ تركيز ولوحة مفاتيح (Esc/Enter/Tab).

### 8هـ. إحصاءات الزيارات (اختيارية)
